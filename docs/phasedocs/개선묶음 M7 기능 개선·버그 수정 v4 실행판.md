### G. `\Rightarrow` — **수용**, 정돈의 결정적 세트에

`$\Rightarrow …$`(안쪽 앞머리, 공백 허용, 뒤가 영문자가 아님) → `⇒ $…$`; 나머지가 비면 `⇒`. 수식 **중간**의 `\Rightarrow`는 무접촉. display `$$…$$`는 무접촉. `\Leftrightarrow`·`\iff`·`\Longrightarrow`는 제외(프롬프트가 `$\iff$`를 권장 표기로 쓴다). 구현 위치는 `proofread.ts`의 결정적 세트(④번째 규칙으로 추가) — D19-4로 그 세트가 정돈 소유가 되므로 스케치의 "proofread에 추가"와 실질이 같다. **G′(v3 보완)**: `\Rightarrow` 뒤에 붙은 간격 명령 `\ `·`\,`·`\;`·`\quad`·`\qquad`·`~`를 함께 걷는다(안 걷으면 `⇒ $\ x$` 잔재가 남는다). `$\Rightarrow$` 단독은 `⇒`. ⚠ 뒤이어 ③ 조사 공백 규칙이 `⇒ $x$이므로` 꼴을 건드리지 않는지 테스트로 고정.

export function computeCenterScrollLeft(
  scroller: { left: number; right: number }, cursorLeft: number, scrollLeft: number, margin = 24,

  if (cursorLeft >= scroller.left + margin && cursorLeft <= scroller.right - margin) return scrollLeft;

### 8-3. CLAUDE.md에 남길 규약 (S10)

- **`$$` 스캐너는 `lib/mathRegions.ts` 하나다(M7 D2·D3)**: 같은 행에 닫는 `$$`가 없는 `$$`는 **빈 인라인 쌍**(길이 0, 진단 없음, `isInsideMath` true). 편집창 쪽 6 소비처에 `$$` 정규식·char scan 사본을 다시 만들지 말 것. 렌더·저장 경로(`locale.ts`·`preprocess.ts`·`mathIndex.ts`)는 별개(범위 밖).
- **`$` 버튼은 인접 `$`일 때만 공백을 붙인다(D1)** — 마크다운은 `$a$$b$`를 수식 하나(`a$$b`)로 읽는다. `$ $`로 바꾸지 말 것.
- **끔 모드 가로 추적은 두 정책이다(D5)**: 타자·삭제 = 경계에 닿으면 중앙(`centerCursorOnEdge`, measure write가 CM nearest보다 먼저 돈다) / 프로그램적 이동 = 경계까지만(`revealCursorX`). `EditorView.scrollIntoView` 금지는 그대로.
- **Row 1은 저장까지, Row 2는 탭까지 민다(D7~D9)** — 클러스터(버전·댓글·Agent·스테퍼 2)는 절대배치 `right 16 · zIndex 10 · height 56`이고 드로어 밑으로 들어간다. 2026-08-28의 "Row 1·2는 밀지 않는다"는 부분 철회.
- **저장은 편집기를 리마운트하지 않는다(D11)**: 로컬 블록 id는 세션 내내 유지되고 `origBlockIds`만 서버 id다. 저장 뒤 `setAllBlocks(서버본)`을 되살리지 말 것 — 저장 중 친 글자가 사라지고 커서가 날아간다. dirty 해제는 `editSeqRef`(dirty effect가 센다 — deps에 `problem`이 **없다**)가 저장 시작값과 같을 때만이고, 저장 안에서 `skipDirtyRef`를 만지지 않는다(옛 코드는 `setProblem` 뒤 `await` 사이에 effect가 먼저 돌아 첫 편집의 dirty를 삼켰고, 검증 완료의 `setProblem`은 헛 dirty를 찍었다 — 2026-09-12 발견 2건, D11 v4로 소멸). `problem`을 dirty deps에 되돌리지 말 것. ⚠ undo·redo·복원의 세대 id 재생성·리마운트는 의도라 손대지 말 것.
- **30분 자동 저장은 silent다(D12·D13)** — 스냅샷 없음, 기준점은 마지막 저장. Phase 55 D2 개정. 드래프트는 그대로 크래시 안전망.
- **블록 클립보드는 메모리 싱글턴(D15)** — 시스템 클립보드 미사용. 붙여넣기는 접힘 모드에서만, 빈 탭은 맨 앞. 미디어 블록은 URL 공유(D17) → **장래 Storage 정리 기능을 넣으면 참조 수 문제가 생긴다.**
- **교정 = API 내용 검토, 정돈 = 분할 + 결정적 정형화(D19-4)** — `autoFixDeterministicIssues`의 소비처는 `lib/blockTidy.ts` 하나. 교정 버튼에 결정적 규칙을 되돌리지 말 것. 시트 가져오기 토글 이름은 "블록 정돈".
- **경우 라벨은 AI 경계에서만 붙인다(D20)** — raw_text·검증 `text`에 넣지 말 것(인용 앵커). 검증은 `[블록 n] (case C1)` 헤더, 토론·⌘J는 `C1. ` 접두. 원천은 `buildCaseLabels` 하나.
- **CM 툴팁의 부모는 body가 아니라 0×0 fixed 호스트다(D25′, 2026-09-12 사고)**: CM은 `tooltips({parent})` 컨테이너에 `view.themeClasses`를 통째로 붙이므로 `EditorView.theme({'&': …})`의 **모든 `&` 규칙이 그 컨테이너에도 적용된다**. body 직속이던 때 `'&': { height: '100%' }`가 뷰포트 높이 div를 블록 수만큼 만들어 문서가 넘쳤다(Phase 65 S11 이후 편집창 휠 끝에서 화면 전체가 밀리던 버그). 호스트에 `overflow`·`transform`을 주지 말 것. 편집창 스크롤러 2개는 `overscroll-behavior-y: contain`(D22) + `window` 스크롤 트립와이어(D23)로 이중 방어. `html, body { overflow: hidden }`은 넣지 않는다(공개 라우트·폰 셸).
- **ProblemView 제목행 우단 클러스터 = 댓글·agent·스테퍼(D26)** — 절대배치 래퍼 하나, `rightReserve` 미가산이라 드로어가 열리면 셋이 함께 덮인다(의도). h1엔 제목·원본인증 배지만.
- **사이드바 헤더에 bold 아이콘·700 글자는 없다(D28~D30)** — M6 검수 6차 판정 철회(덕수 2026-09-12). 위계는 아이콘 톤(`--text-primary` vs 행 `--text-secondary`) 하나. "아이콘 체계" 절의 bold 예외는 **0종**.

### 8-4. 하지 말 것 (CLI 착수 중)
`.cm-scroller`·블록 CM 체인에 px 높이 · 테마에 `overflow` 재기술(Compartment 규약) · `EditorView.scrollIntoView` · 네이티브 `alert` · Row 2에 네이티브 `title` 병기 · 생성 파일 `phosphorPaths.ts` 수동 편집 · `splitFigures`·`rowToDraft` 수정 · `synthesizeVerdict`에 새 필드 전달 · dev 서버 켠 채 `npm run build`.
