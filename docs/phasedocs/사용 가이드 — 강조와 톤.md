# 사용 가이드 — 강조와 톤

Phase 58에서 도입된 강조 체계의 사용법. 에디터 도움말 UI가 생기면 이 내용을 옮긴다.

---

## 강조의 두 축은 서로 다른 일을 한다

| 원하는 것 | 수단 | 결과 |
|---|---|---|
| **위치**를 강조 (한 덩어리를 들여쓰기) | **강조문 블록**(callout) | 왼쪽 끝이 독립행 수식과 같은 자리로 들어간다. **색은 바뀌지 않는다** |
| **색과 굵기**로 강조 (핵심 문장) | 인라인 `**…**` | 그 구간만 진하고 굵게 뜨고, 나머지 풀이는 한 톤 물러난다 |

따로 써도 되고 같이 써도 된다. "들여쓴 자리에 있는 핵심 문장"이면 강조문 블록 안에서 `**`를 쓰면 된다.

> 강조문 블록만 쓰고 `**`를 쓰지 않으면 색은 그대로다. 들여쓰기만 필요할 때 쓰라고 만든 블록이기 때문이다.

---

## 핵심문장(`**`)을 쓰면 풀이 전체의 톤이 내려간다

풀이에 `**`가 **하나라도** 있으면 그 풀이의 나머지 부분(글자·수식 모두)이 한 톤 물러나고, `**` 구간만 진하고 굵게 남는다. 계산 전개는 뒤로 물러나고 핵심 아이디어가 앞으로 나오게 하는 장치다.

- `**`가 **하나도 없으면** 아무 변화도 없다. 기존 문항은 손대기 전까지 그대로다.
- 원치 않으면 `**`를 지우면 바로 꺼진다.
- **문제 탭에는 적용되지 않는다.** 풀이·추가 탭에서만 동작한다.
- **인쇄는 예외다.** 흑백에서는 색 위계가 죽으므로 전체를 원래 톤으로 되돌리고 핵심문장만 굵게 찍는다.

### 툴바 "핵심문장" 버튼

문장을 선택하고 누르면 `**`로 감싸지고, 다시 누르면 벗겨진다. 손으로 칠 때 틀리기 쉬운 것들을 대신 정돈해 준다:

- 선택 양끝의 공백을 빼 준다 (`** 문장 **`는 강조가 되지 않는다)
- 행 끝 참조번호 `\tag{3}`은 자동으로 뺀다 (포함하면 번호가 깨진다)
- 문단을 넘는 선택, 수식 중간을 자르는 선택은 **거부**한다 (버튼이 흔들린다)

되돌리기(⌘Z) 한 번이면 원상복구된다.

---

## 독립행 수식은 `**`로 감쌀 수 없다

`$$…$$`은 블록 문법이라 인라인 강조 `**`가 통하지 않는다. 색으로 강조하고 싶으면 **인라인 수식으로 바꿔서** 감싼다:

```
$$x=\frac{-b\pm\sqrt{b^2-4ac}}{2a}$$        ← 강조 불가

**$x=\frac{-b\pm\sqrt{b^2-4ac}}{2a}$**      ← 강조 가능
```

크기와 조판은 그대로다 — Mathory는 인라인 수식에도 `\displaystyle`을 자동으로 넣기 때문이다.

**들여쓰기까지** 원하면 그 행을 강조문 블록에 넣는다. 강조문 블록의 왼쪽 끝은 독립행 수식과 같은 위치라 x좌표가 어긋나지 않는다.

### 여러 행짜리 수식

`$$ A \\ B $$`처럼 `\\`로 행을 나눈 수식은 인라인 하나로 옮길 수 없다(인라인 모드는 줄바꿈을 지원하지 않는다). **한 줄에 하나씩** `$…$`로 나눠 쓴다.

`\begin{cases}` 같은 환경 안쪽의 `\\`는 인라인에서도 정상 렌더되므로 그대로 두면 된다.

---

## 알아둘 것

- **핵심문장 안의 수식은 굵어지지 않는다.** 색만 진해진다. KaTeX가 수식 글꼴의 굵기를 자체적으로 고정하기 때문이며, 수학 글리프가 가짜 볼드로 뭉개지지 않는 편이 조판상 낫다.
- **제목은 톤 변화의 영향을 받지 않는다.** 문항마다 제목 색이 달라지지 않도록 고정해 두었다.
- **이미지·그래프도 그대로다.** 흐려지지 않는다.
