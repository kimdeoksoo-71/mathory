## 1. 확정 사실 (`17f1128` 실측)

| # | 사실 |
|---|---|

| **A-2** | ⚠⚠ **보기의 정의부는 문제 탭에 산다**: `ㄱ.`·`(가)`·`①`(목록 블록)·텍스트행 `\tag`. 문제 카드를 **언마운트하면 풀이의 참조 말풍선이 전부 무음**이 된다(`5c242b3`에서 이미 겪었다). 새 설계는 "풀이를 읽는 내내 카드가 숨겨진 상태"라 **보기 유형 문항에서는 상시 발생**한다 |
| **A-3** | 반대로 `\tag{n}` → `(3)` 인용은 **대개 풀이 탭 안에서 닫힌다** → 카드 숨김과 무관. 선택지 `①`은 `ChoicesBlock`이 라벨을 평범한 `<span>`으로 분리 렌더하므로 **애초에 정의부가 아니다** |

| **C-2** | 폴더뷰 카드 하단 페이드는 **카드 자신의 배경(`--card-surface`, 클레이)** 으로 사라진다(`globals.css` 카드 절). 메모가 인용한 것이 이 문법이다 |

## 2. 결정표 (v1)

### P. 제목행 고정 + 문제 카드 토글 (메모 항목 1)

| # | 결정 |
|---|---|
| **P1** | 제목행에서 **자동접힘을 걷어낸다**: `headerSlim`·`HEADER_H`·슬림 바 축약 제목·`borderBottom` 분기·D49(컨트롤 top 연동)·`font-size` 트랜지션 전부 삭제. 제목행은 항상 `minHeight 98`이다 |
| **P2** | 문제 카드 표시 상태를 `questionShown`(기본 `true`)로 둔다. `contentScrollRef`의 `onScroll`에서 **`scrollTop > T1`이면 1회 `false`**. 되돌리는 자동 경로는 없다(E-P3) |
| **P3** | ⚠⚠ **숨김은 언마운트가 아니다.** 카드 래퍼를 `position:absolute; visibility:hidden; pointerEvents:none`로 두어 **DOM에 남긴다**(A-2). M2의 접힘 처방을 그대로 승계한다. 라벨 열도 같이 숨긴다 |
| **P4** | 알약 버튼: 제목 오른쪽·`--accent-primary`·흰 글자 12px/600·radius 999. `questionShown`이면 `문제 감추기`, 아니면 `문제 보기`. **최초 진입(아직 숨긴 적 없음)에는 렌더하지 않는다**(Q8) |
| **P5** | 제목 span에 `min-width:0` + 말줄임, 버튼·배지·💬·AI에 `flexShrink:0` — 긴 제목에서 버튼이 밀려 사라지지 않게(M2 D-17의 재발 방지) |
| **P6** | 문제 카드는 **sticky를 뗀다**(E-P4). 이에 따라 `questionRowRef`·`qStickyH`·`--m2-q-sticky-h`·`lastQHRef` 델타 보정·`handleJumpToBlock`의 sticky 오프셋(D29′)이 **전부 삭제**된다 |
| **P7** | 풀이 라벨 열의 `sticky top`은 변수가 아니라 **고정값**이 된다(제목행 아래 선 기준) |

### Q. 풀이 카드 상단 선·페이드 (메모 항목 2)

| # | 결정 |
|---|---|
| **Q1** | 선·페이드를 **`scrolled`(= `scrollTop > 4`) 일 때만** 렌더한다. 최상단에서는 풀이 카드의 둥근 모서리와 상단 테두리가 정상으로 보인다 |
| **Q2** | 선은 **sticky로 상단에 남긴다**. 문제 카드가 보이는 동안에는 카드 아래에, 숨겨지면 제목행 바로 아래에 온다 — 선을 **카드 래퍼의 아래**에 두면 분기 없이 자동으로 성립한다 |
| **Q3** | 페이드를 sticky 래퍼(아이보리)에서 **풀이 카드 안쪽 상단**으로 옮기고 색을 **클레이(`--bg-content`)** 로. 지금 자리에서 색만 바꾸면 카드 사이 8px 틈에 클레이 띠가 생긴다. 옮기면 폴더뷰 카드 하단 페이드(C-2)와 같은 문법이 된다 |
| **Q4** | 그라디언트 색은 **토큰을 그대로** 쓴다(하드코딩 rgba 금지 — `78a780f` 사고) |

### R. 좌측 라벨 간격 · rail 좌표 (메모 항목 3·5 — 한 묶음)

| # | 결정 |
|---|---|
| **R1** | `LABEL_GAP_EM 2.8 → 1.4`(fs15에서 42 → 21px). B-2로 안전하다. `TabBody.tsx:36`의 낡은 주석을 **함께 고친다** |
| **R2** | `--case-rail-x: -1.8em → -1.3em`(카드 좌단과 본문 좌단의 중간). dot 좌단은 `-1.56em` |
| **R3** | ⚠ **`CARD_PAD_L`을 px에서 em으로**(`40px → 2.8em`, fs15에서 42px ≈ 현행). B-1의 결함을 함께 고치는 것이며, 이것 없이 R2만 하면 fs24에서 여전히 아슬아슬하다(8.1px) |
| **R4** | 공개 뷰어 `PublicViewerShell`의 `ContentCard`(`padding '32px 36px 32px 40px'` + `maxWidth calc(35em + 76px)`)도 **같은 구조**다 — 함께 볼 것 |

### S. 요약 보기 노브 제거 + 톤 (메모 항목 4)

| # | 결정 |
|---|---|
| **S1** | **경우 줄 chevron(`.case-head .outline-chevron`)만 제거**한다. 거터에 절대배치돼 rail 이동과 직접 충돌한다. **제목 줄 chevron은 유지** — 요약 보기에서 "무엇이 접혀 있는가"를 알리는 유일한 표시다 |
| **S2** | 톤 사다리: 카드 기본 `--bg-content` → 1단계 `--block-bg` → 2단계 `--block-bg-active`. 접힘 hover = 2단계, 펼침(상시) = 1단계 |
| **S3** | 톤 영역을 **카드 좌우 경계선까지** 넓힌다: 음수 마진 `-(CARD_PAD_L) / -(CARD_PAD_R)` + 같은 크기 패딩. ⚠ R3로 `CARD_PAD_L`이 em이 되므로 **같은 상수를 참조**할 것(숫자를 굳히면 갈린다) |
| **S4** | ⚠ 관찰 대상: 펼친 구역이 여럿이면 카드가 얼룩덜룩해질 수 있다. 1단계로 만들고 **실물 검수에서 판단**한다 |
