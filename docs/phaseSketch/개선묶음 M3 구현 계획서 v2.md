## 2. B4 — 제목바 클릭 상하 떨림 (v1 §2 + D7 확정)

원인: `.outline-section.is-open`에만 있는 상하 패딩 0.3em(`globals.css:962-968`) + `.is-open + .is-open`의 margin-top 0.4em(`:969`). 좌우는 상시(주석 `:955`)로 설계돼 있고 상하만 그 처방에서 빠졌다.

**확정 처방(D7)**: 패딩·인접 마진을 **같은 값의 음수 마진으로 상쇄**해 흐름 높이를 불변으로 만든다 — 톤 상자는 내용보다 0.3em 크게 그려지되 여닫아도 아무것도 밀리지 않는다.
- 선행 실측: 형제 섹션 간 자연 간격이 0.3em(상쇄로 생기는 겹침)보다 큰지 — 11/15/24px 세 글꼴에서(Phase 59a C5 규약).
- `.is-open + .is-open { margin-top: 0.4em }`도 같은 방식으로 함께 — 남기면 "이웃이 열려 있을 때만" 떨림이 재발한다.
- 검수: 요약보기에서 제목·전문·경우 여닫이를 각각 클릭하며 **위쪽 내용의 화면 좌표가 1px도 안 움직이는지**(DevTools rect 대조).

## 3. B3 — '앞부분 펼치기' 헛표시 (v1 §3 + D6 확정)

**확정 처방(D6)**: `buildOutline`(`lib/solutionOutline.ts`)이 섹션 생성 시 **"요약 항목으로 닿을 수 없는 블록"** 존재 여부를 계산해 `OutlineSection.hasHiddenBlocks`로 싣고, 전문(前文) 여닫이는 그 값이 참일 때만 그린다.

- heading 섹션에는 적용하지 않는다(제목은 원래 표시되는 내용).
- 테스트: `test:case` +4건(pinned 시작 → 없음 / 앞에 일반 텍스트 → 있음 / 레거시 라벨 → 있음 / 경우로만 시작 → 없음).

### Mathory 통합 실측과 사양

| 항목 | 실측 | 사양 |
|---|---|---|
| KaTeX 버전 | **0.16.28**(package.json) — 문서의 검증 버전(0.16)과 일치. CSS는 `app/layout.tsx:24` CDN + `PrintableContent` import로 이중 로드 | 선택자 그대로 사용 가능. v3에서 0.16.28 DOM 스냅샷 재확인(§7-③) |
| CSS 주입구 | **`globals.css` 한 곳이면 화면·인쇄를 다 덮는다** — 인쇄는 iframe이 아니라 같은 document라 globals가 인쇄 노드에도 전부 적용된다(기존 규약) | `.katex { --frac-ext … }` 규칙을 globals.css에. PrintStyles 사본 불필요. ⚠ 스코프를 `.preview-content`로 좁히지 않는다 — 검증 카드·폴더뷰 카드의 분수도 가로바 연장을 받아야 화면 간 조판이 갈리지 않는다 |
| 매크로 주입구 | rehype-katex 옵션 **사본 2곳**: `EditorPreview.tsx:316` · `PrintableContent.tsx:137`(이미 `\arraystretch` 사본 전례) | **`lib/katexMacros.ts` 신설(import 0)** — `KATEX_MACROS = { '\\arraystretch': '1.8', ...FRAC_GAP_MACROS }` 한 벌을 두 곳이 import. 기존 사본 2곳 문제도 함께 해소(MARKER_LINE_RE 전례) |
| 검증 카드(`katex-render.ts:16`) | `renderToString(…, { displayMode: false })`, macros 없음 | **매크로 제외(현행 유지)** — 11~12px 카드에서 팬텀 0.2em×2가 줄높이를 흔들 위험 대비 이득이 없고, CSS 가로바 연장은 전역이라 어차피 적용된다. v3 반박 대상(§7-④) |
| 인라인 수식 | ⚠ Mathory는 **인라인에 `\displaystyle`을 자동 주입**한다(`lib/preprocess.ts:145`) — 문서의 "인라인 제외하려면 `\dfrac`만" 갈래는 Mathory에서 의미가 다르다(인라인도 이미 display 조판) | D8 수용대로 **3종 전부** 적용. 목업 마지막 줄("본문 인라인")이 이 경우의 승인 표본이다. 검수에서 인라인 든 문단의 줄간을 11/15/24px로 확인 |
