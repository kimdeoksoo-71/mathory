## 2. 덕수 실측 (한글 2022)

### S-1 · S-12 — 스타일 덮어쓰기 (착수 직후)
파일: `S1-A-기준(빨강)` · `S1-B-같은한글이름(파랑14pt)` · `S1-C-같은영문이름(초록)`

1. **A를 연다.** 첫 문단이 빨강, 가운데 일부가 굵은 글씨인지 본다.
2. 메뉴 **서식 → 스타일(F6)** → 스타일 창 아래쪽의 **'스타일 가져오기'** 버튼 → 파일 선택에서 **B**를 고른다.
3. 목록에서 **문제-본문**을 골라 가져오기 → "같은 이름의 스타일이 있습니다 — 덮어쓸까요?"에 **덮어쓰기**.
4. A의 문단이 **파랑 14pt**로 바뀌면 → **한글 이름이 짝 맞춤 키**(S-1). 그대로 빨강이면 → 영문 이름이 키일 가능성.
5. 같은 화면에서 S-12: 굵은 부분이 **① 여전히 굵은지 ② 파랑 14pt로 같이 바뀌었는지**.
6. A를 **저장하지 말고 닫고 다시 연다** → 이번엔 **C**에서 가져오기(목록 이름은 "다른이름") → A의 "문제-본문"이 **초록**이 되면 영문 이름도 짝을 맞춘다.
