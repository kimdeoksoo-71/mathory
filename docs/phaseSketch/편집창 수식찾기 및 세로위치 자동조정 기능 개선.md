EditorView 편집창, 미리보기창 버그 잡기 및 기능 개선

1. 버그 1 :   
   1. 내용 : 편집창의 맨 위 블록의 윗쪽 2\~3줄이 상단 경계선 안쪽으로 밀려올라가서 스크롤을 해도 내려오지 않음  
   2. 고질적으로 발생해왔음. 두 번 이상 잡았는데도 다시 재발함. 근본적인 원인을 찾아서 규명하고 재발 방지를 위한 근본적인 대책을 세우자.  
2. 버그2 :   
   1. 내용 : 왼쪽 편집창에서 수식을 클릭했을 때 오른쪽 미리보기창에서 해당 수식을 찾아 배경색을 강조색으로 바꾼 후 세로 가운데 위치로 이동시키는 기능의 불완적 작동, 또는 불편한 작동  
   2. 불편한 작동 (1) 편집창에서 수식 Latex 태그를 클릭하거나 또는 미리보기창에서 랜더링된 수식을 클릭했을 때, 양쪽 창에서 수식 Latex 태그, 랜더링된 수식이 모두 세로 가운데 위치로 이동했으면 해. 그런데, 각각의 세로 위치가 임의로 설정되어서 제각각 움직여.   
   3. 불편한 작동 (2) 왼쪽 편집창에서 현재 활성화된 블록이 아닌 다른 블록의 수식을 클릭하면 오른쪽 미리보기창에서 해당 수식의 배경색이 강조색으로 바뀌는 기능이 작동하지 않아. 같은 블록 안에서 다른 수식을 다시 클릭하면 그때는 강조색 기능이 작동해. 원인을 찾고, 어떤 경우든 강조색이 예외없이 작동하도록 수정하자.   
3. 기능개선 : 편집창 입력시 세로 위치 자동 조정 기능  
   1. 내용 : 편집창에서 내용을 입력할 때, 현재 커서가 편집창의 마지막행에 도달하면 현재 활성화된 행이 자동으로 편집창의 세로 중앙 위치로 이동하도록 하는 기능  
   2. 이와 같은 기능을 구현하는것이 가능한지 검토한 후 가능하다면 구현해줘.
