## 2. 실측 (xlsx 내보내기 2026-11-05)

### 2-1. 연결 재료가 이미 80% 있다 — `_CroP색인` 시트
- 문항장부에 `_CroP색인` 시트(2026-10-24 "CroP 이미지 삽입" 작업이 남김). 열: 파일키·문항ID·시트·행·사용세트식별·문서URL·문제파일ID·해설파일ID·해설조각수·상태·메시지·처리시각.
- **1,815행 = 대량변환 v4의 Data_DS 1,815문항(행 4490~6304)과 1:1** (정규화 후 1,814 일치, 양쪽 1건씩 stray).
- 상태: ✅ 1,444 / ❌ 매칭없음 369 / ❌ 문제파일없음 1 / ❌ 중복 1.
- ❌ 369 = **24년 홀수 모의X 8세트(01·03·…·15) × 46 = 368** + 1. 이 세트들은 문항장부 Data에 `사용세트식별`이 없다(24년은 X.0·X.02·…·X.16 짝수만 등록). → 키 형식 문제가 아니라 **등록 자체가 없음**.
- 누락 의심 1건: 색인 ❌ `25X모의12_1공통20` — Data에 `25.X.12:1 공통:20`(D5008)이 실제 존재.

### 2-2. 키 표기가 두 파일에서 다르다
| 쪽 | 표기 | 예 |
|---|---|---|
| 문항장부 `_CroP색인` 파일키 | `YYX모의NN` · `YYX서킷NN` (사용세트식별에서 파생) | `24X모의06_1공통02` |
| Latex 변환 Data_DS A열 (= 실제 CroP 파일명) | `YY모의XNN` · `YY서킷XNN` | `24모의X06_1공통02` |
| 문항장부 Data 등록 메모 | 두 표기 혼재 (X모의 628 · 모의X 197 · 서킷X 19, 스니펫 기준) | — |
- 정규화 규칙 1개(`^(\d2)X(모의|서킷)(\d2)` → `\1\2X\3`, 써킷→서킷)로 1,814/1,815 흡수.
- 그러나 **영구 연결은 표기 변환이 아니라 D-ID를 데이터에 박는 것**이어야 한다(덕수님 요구와 일치). 표기는 또 바뀔 수 있다.

### 2-3. 문항장부 사용세트식별 체계
- 24년: `X.06:1 공통:2` (연도 없음) / 25·26년: `25.X.12:…`, `26.X.03:…` / 써킷: `25.써킷X.14:…`, 24년 써킷은 `써킷.X.23:…`.
- 과목 표기 `1 공통`·`3 확률과 통계`·`4 미적분`·`5 기하` ↔ CroP `1공통`·`3확통`·`4미적`·`5기하`.

### 2-4. 문제검색 시트 구조
- 1행 = 검색 조건(B1 연도·C1 출세트·E1 사세트·I1 유형·L1 대단원·M1 태그, 선택항목 시트 드롭다운). A2 = `FILTER(Data!A2:R…)` + SORT.
- **선택 체크박스 열('선택', U열)과 체크된 행의 보기 URL을 모으는 수식(T열 `filter($N:$N,$S:$S=true)`)이 이미 있다.** → "검색 → 체크" 동작은 이미 존재.

### 2-5. Latex 변환 Data_DS 빈 열
- 헤더 A~K(`id … answer_type`), **L열 이후 빈 열**. Mathory 매핑(`SHEET_COL`)은 K·L·N을 읽지 않는다 → **L열에 무엇을 써도 Mathory·GAS 어느 쪽도 깨지지 않는다.**

## 5. 문제검색 S·T·U열 실측
| 열 | 1행(머리) | 2행 이후 | 비고 |
|---|---|---|---|
| A~R | ID … 중복 | `FILTER(Data!A2:R, …)` 결과 18열 | Data 시트 A~R을 그대로 가져옴 |
| S | (없음) | (전부 빈칸, 3,444행 중 0) | — |
| T | (없음) | T2만 `=filter($N:$N, $S:$S=true)` | S가 비어 조건이 참인 행이 없음 → `#N/A` |
| U | `선택` | 체크박스(FALSE) 3,443개 | 실제 선택 열 |
- 추정: 예전에는 FILTER 결과가 A~P(16열)이고 체크박스가 S열에 있었는데, Data에 `사용세트식별`(Q)·`중복`(R)이 추가되며 FILTER가 R까지 넓어지고 체크박스를 U로 옮기면서 T2 수식을 안 고친 것.
- 2층 수식: `=TEXTJOIN(",",TRUE,FILTER(A2:A, U2:U=TRUE))`. T2는 지워도 되고, 고치려면 `$S:$S`→`$U:$U`.
