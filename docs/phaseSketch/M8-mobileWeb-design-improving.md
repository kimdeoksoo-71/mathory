* 디자인  
  * Mathory 로고 (시작페이지 상단) : 최근 로고 개선 사항 반영  
    * 최근 개선사항&nbsp;  
      * 글꼴 얇게, 글자 색 더 진하게  
      * 은은한 띄움효과  
  * 모바일 웹의 ProblemView의 2행에 탭버튼이 상주하므로  
    * 문제 탭에서 하단의 ‘풀이 보기’ 버튼 삭제  
    * 풀이 탭 등 문제탭이 아닌 탭에서 빨간알약 모양의  ‘문제보기’서튼 삭제&nbsp;  
  * 댓글, ai agent 하단 드로어에서 외곽상자 없애기  
    * 이유 : 하단 드로어가 이미 상자형태라서 상자속의 상자(이중)로 상자가 중복, X 표 (꺼짐 버튼)이 2개로 중복  
    * 공간 낭비로 컨텐츠 공간이 비좁아짐&nbsp;  
    * 개선 방향 : 상자, 테두리, 꺼짐버튼(X) 제거  
      * 드로어 안의 상자, 외곽선, 외곽선 밖의 여백을 모두 제거하여 컨텐츠 영역의 면적을 최대로 확보  
      * 드로어의 1행(아이콘과 제목, 기타정보), 2행은 유지  
      * 행 구분 가로선 및 기타 디자인 요소는 그대로  
* 모바일 웹 ProblemView 가로보기 전환시 컨텐츠 공간 최대화 기능 도입  
  * 기능 도입 취지 :  ProblemView 에서 폰을 가로로 돌리면 1행, 2행이 차지하는 공간이 전체 면적의 절반 가까이됨. 가로 확대보기의 장점이 살지 못함  
  * 기능 개요  
    *  ProblemView 에서 폰을 가로 보기 상태로 전환한 후 정방향스크롤을 하면 1행(제목행), 2행(탭 이름 행)이 자연스럽게 위로 사라짐  
    * 역방향 스크롤을 하면 마지막에 1행, 2행이 다시 나타남  
  * 기대 효과 : 가로 보기 상태에서 폰화면 전체를 모두 문제, 풀이를 나타내는데 쓸 수 있어 내용에 집중할 수 있고, 더 많은 내용을 볼 수 있음
