## 4. 보안 규칙 변경 (`firestore.rules`)

> 적용 대상: `problems/{problemId}` 하위의 두 match 블록(일반 서브컬렉션 `{subcollection}/{docId}`, `tab_comments/{commentId}`).
> `isSignedIn()`은 상위 `problems` match에 정의되어 하위 match에서 호출 가능. `parentIsPublic()`은 일반 서브컬렉션 match에만 존재하므로 tab_comments match에는 **별도 정의 추가**.

### 4-1. 블록 읽기 public 탭 필터 (D1)
일반 서브컬렉션 match에 `tabAllowedForPublic()`를 추가하고, public 갈래에 블록 탭 게이트를 건다. (`parentData`/`tabIdFromSubcol`/`isBlocksSubcol`/`tabAllowedForMember`는 **이미 존재** — 그대로 재사용.)

```
// 추가
function tabAllowedForPublic() {
  return parentData().get('memberTabVisibility', {})
    .get(tabIdFromSubcol(), true) == true;
}

// 기존 read 라인을 아래로 교체 (public 갈래에 블록 탭 게이트 추가)
allow read: if !isCommentsCol() && (
  parentOwner()
  || (parentIsPublic() && (!isBlocksSubcol() || tabAllowedForPublic()))
  || (parentIsMember() && (!isBlocksSubcol() || tabAllowedForMember()))
);
// 쓰기는 기존대로 오너만: allow write: if !isCommentsCol() && parentOwner();
```
> 주의: 멤버·공개가 `memberTabVisibility`를 공용한다(§6). 멤버용≠공개용 탭 노출 분리는 비목표(§10 알려진 제약).

### 4-2. tab_comments 읽기 — 공개 + 로그인 (D2)
tab_comments match에 `parentIsPublic()`를 정의하고 public+로그인 읽기 갈래 추가.

```
// tab_comments match 안에 추가
function parentIsPublic() {
  return parentData().get('visibility', 'private') == 'public';
}

// 기존 read 라인을 교체
allow read: if isOwnerCmt()
  || (isMemberCmt() && commentsVisible())
  || (parentIsPublic() && isSignedIn() && commentsVisible());
```
⚠️ agent 메시지 누출(D3): 규칙 레벨에선 공개 로그인 사용자가 agent 메시지도 읽을 수 있음. 뷰어가 `isCommentStream`으로 UI 차단(§5). 규칙 레벨 누출은 수용(민감 문항 공개 금지 안내).

### 4-3. tab_comments 생성 — 비멤버 로그인 commenter (D2)
기존 **인간 댓글** create 조건의 내부 `( isOwnerCmt() || (멤버…) )` 그룹에 public 갈래를 **OR로 추가**(AI 댓글 갈래는 그대로). `author 본인·human·resolved=false`는 기존 상위 조건이 그대로 강제.

```
// 인간 댓글 갈래의 권한 OR 그룹에 추가
|| (parentIsPublic() && isSignedIn() && commentsWritable()
    && isCommentSessionRef(request.resource.data.get('discussionSessionId', null)))
```
> `isCommentSessionRef(null)==true` — 공개 댓글은 `discussionSessionId=null`(legacy 버킷)로 작성하면 되고 **댓글 세션을 미리 만들 필요 없음.** non-null을 넘기면 `type=='comment'` 세션만 통과하므로 agent(normal) 세션 오염은 차단된다. (※ §10의 "세션 생성 권한 (a)/(b)" 논쟁 폐기 — null 경로로 해소.)

### 4-4. 모더레이션 — 오너 인간 댓글 delete 허용 (D4)
**기존 delete 규칙을 통째 교체하지 말 것.** AI-삭제(오너) 갈래를 보존하고 인간 댓글 갈래에만 `|| isOwnerCmt()`를 머지한다.

```
allow delete: if (
  resource.data.get('authorType', 'human') == 'human'
  && (resource.data.authorUid == request.auth.uid || isOwnerCmt())   // ← 오너 모더레이션 추가
) || (
  resource.data.authorType == 'ai'
  && isOwnerCmt()                                                    // ← 기존 유지(회귀 금지)
);
```
> 정책 변경: 기존 주석 "오너도 남의 댓글 삭제 불가"는 모더레이션 도입으로 폐기 — 주석도 갱신.

### 4-5. commentSessionId 포인터 — 규칙 변경 없음, 데이터/lib만 (P1 핵심)
공개 뷰어는 `discussion_sessions`를 읽을 수 없다(read=`isOwnerSess()||isMemberSess()`). 그래서 `isCommentStream` 필터가 오너/멤버의 댓글-세션 태깅 댓글을 식별하지 못한다. **`problems/{id}.commentSessionId` 단일 포인터를 비정규화**해 public-readable한 problem 문서에서 읽게 한다.

- **규칙 추가 없음**: `problems` update는 `isOwner()`가 이미 커버 → 오너가 `commentSessionId`를 쓰는 경로는 추가 규칙 불필요.
- `ensureCommentSession`이 세션 생성/확정 시 `commentSessionId`를 problem에 1회 기록(§5).
- §3 "비정규화 없음" 원칙의 **유일한 예외** — 세션 리스트 쿼리 의미를 건드리지 않는 단일 포인터라 정당화. 댓글 수는 여전히 클라 계산.







## 5. Live 공개 뷰어 (`app/p/[problemId]/page.tsx`) + lib 신설

> ⚠️ D5의 "/shared 뷰어 재사용"은 **렌더링(`TabContent`)에 한정**된다. `/shared`는 동결 스냅샷(`share.snapshot.tabBlocks`)이라 live-read 코드가 0이다. 실시간 본문은 **신규 구독 헬퍼**가 필요하다.

### 5-1. lib 신설 — 블록 실시간 구독 (`lib/firestore.ts`)
현재 `lib/firestore.ts`에 블록용 `onSnapshot`이 전무(전부 `getDocs`). `onSnapshot`을 import에 추가하고 탭별 구독 헬퍼 신설.

```ts
// import 줄에 onSnapshot 추가
import {
  collection, doc, getDocs, getDoc, addDoc, updateDoc, deleteDoc,
  query, where, orderBy, serverTimestamp, Timestamp, limit, onSnapshot,
} from 'firebase/firestore';

/**
 * Phase 51: 한 탭의 블록을 실시간 구독(공개 live 뷰어용).
 * 규칙(4-1)이 public 탭 게이트를 적용 → 비공개 탭 구독은 permission-denied로 빈 배열.
 * @returns 구독 해제 함수
 */
export function watchTabBlocks(
  problemId: string,
  tabId: string,
  callback: (blocks: Block[]) => void,
): () => void {
  const q = query(
    collection(db, 'problems', problemId, tabSubcollection(tabId)),
    orderBy('order'),
  );
  return onSnapshot(
    q,
    (snap) => callback(snap.docs.map((d) => ({ id: d.id, ...d.data() } as Block))),
    (err) => console.warn(`[watchTabBlocks] ${tabId} 구독 오류:`, err),
  );
}
```
> live 뷰어는 `getPreviewBlocks`를 **쓰지 말 것** — "내용 있는 첫 탭만 반환 + 권한 에러 silent swallow"라 다중 탭 부적합. visible 탭마다 `watchTabBlocks` 구독.

### 5-2. lib 수정 — 댓글 세션 포인터 기록 (`lib/discussion-sessions.ts`)
`ensureCommentSession`이 세션 id를 problem 문서에 1회 기록(P1). `db`는 이미 import — `updateDoc`만 사용(순환참조 회피: `firestore.ts`의 `updateProblem` import 금지).

```ts
import { collection, doc, getDocs, addDoc, updateDoc, deleteDoc,
  query, where, orderBy, limit, serverTimestamp } from 'firebase/firestore';

export async function ensureCommentSession(problemId: string, ownerUid: string): Promise<string> {
  const existing = await getDocs(
    query(sessionsCol(problemId), where('type', '==', 'comment'), limit(1)),
  );
  const sid = existing.empty
    ? (await addDoc(sessionsCol(problemId), {
        type: 'comment', name: '댓글', aiEnabled: false,
        createdBy: ownerUid, createdAt: serverTimestamp(), updatedAt: serverTimestamp(),
      })).id
    : existing.docs[0].id;
  // Phase 51: 공개 뷰어가 problem 문서에서 읽도록 포인터 비정규화(멱등 보정)
  await updateDoc(doc(db, 'problems', problemId), { commentSessionId: sid }).catch(() => {});
  return sid;
}
```

### 5-3. lib 수정 — `mapDoc`이 'comment' 타입 보존 (P3, load-bearing 버그)
`lib/discussion-sessions.ts`의 `mapDoc`이 현재 `data.type === 'public' ? 'public' : 'normal'`로 **'comment'를 'normal'로 뭉갬** → `CommentPanel`의 `sessions.find(s=>s.type==='comment')`가 영구 null, 댓글 세션이 agent 리스트에 유령으로 섞임. Phase 51 필터가 이에 의존하므로 **1단계에서 동봉 수정**.

```ts
// 변경 전: type: data.type === 'public' ? 'public' : 'normal',
type: data.type === 'comment' ? 'comment'
    : data.type === 'public'  ? 'public'
    : 'normal',
```
> 수정 후 에디터 agent 패널에 유령 "댓글" 카드가 없는지, `countAgentSessions`가 정확한지 회귀 점검.

### 5-4. 뷰어 동작 (`PublicProblemView`)
- 살아있는 `problems/{id}`(public read) 구독 + visible 탭마다 `watchTabBlocks` 구독 → 편집 저장 즉시 반영. 탭 게이트는 규칙(4-1)이 강제.
- `TabContent`(/shared) 렌더 패턴 재사용 — `EditorPreview borderless locale="ko"`, `ChoicesBlock`, `imageTreatmentStyle` 그대로.
- 댓글: `CommentPanel`(공개 commenter 모드). **`commentSessionId`는 problem 문서에서 읽어** `isCommentStream(c, commentSessionId)`로 필터 → 오너/멤버 댓글 표시 + agent 메시지 제외. 공개 사용자 작성은 `discussionSessionId=null`(legacy 버킷).
- 비로그인: 본문 + "댓글은 로그인 후"(Google 로그인). 단일 활성 세션(`lib/session.ts`)과의 충돌 여부 확인(P10).
- 비공개 전환: 구독 permission-denied → "비공개로 전환되었습니다" 안내.
- 헤더: /shared 뷰어와 동일 로고/슬로건.
