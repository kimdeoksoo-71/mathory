## phase 62 : 폴더뷰 구조 변경과 좌우 사이드바 UI 통일

* FolderView의 바탕색을 기존의 클레이에서 아이보리(클레이 영역 바깥의 색)로 변경  
  * 취지 : ProblemView와 EditorView는 ‘내가 지금 하나의 문제를 보고 있는거야’ 라는 사실을 직관적으로 전달하므로 ‘문제’를 의미하는 클레이를 바탕색으로 쓰는 것이 맞음. 그러나 FolderView는 ‘지금 하나의 문제를 편집하거나 보고있는 상황에서 나온거야’ 라는 상황 변화를 색으로 직관적으로 전달하는 게 필요함.   
  * 구체적 방안  
    * FolderView에서 기존의 클레이 영역을 걷어낸다. 테두리도 함께  
    * 카드 뷰 :   
      * 카드의 색을 기존의 클레이 영역의 색으로 (기존의 카드를 채운 색은 클레이 영역의 기본 색보다 톤이 진했음)  
      * 카드에 얇은, 카드의 클레이 색보다 살짝 짙은 테두리를 넣는다.  
      * hover 상태의 카드에 그림자 효과와 톤을 살짝 짙게 하는 효과는 기존과 같이 유지한다.  
    * 리스트 뷰  
      * 각 행을 가로로 길고 가늘은 카드 형태로 만든다. 카드뷰에서 본 카드가 가로로 길어지고, 세로로 얇아진 꼴로 보이도록. 테두리도 위의 카드뷰와 동일하게.  
      * 가로폭 : 현재 폴더뷰에서 클레이영역 상단 중앙에 가로 구분선이 남아있음. 각 리스트의 가로 폭은 구분선에 맞춘다.   
      * 세로두께 : 현재 폴더뷰 리스트의 세로두께가 적절하니 그것에 맞춤.  
      * 모서리 둥글게 : 네 귀퉁이는 둥글게 처리   
      * 행과 행 사이에는 약간의 간격을 두어 바탕의 아이보리색의 바닥이 드러나 보이도록 한다.  
      * hover시에 강조 :  위의 카드뷰와 동일. 강조를 위한 그림자 효과가 드러나 보이려면 앞 항목에서 언급한 행과 행 사이의 간격이 필요함. 그림자 전부가 드러나야할 필요는 없으므로 카드뷰의 카드 사이 간격보다는 훨씬 좁아야 함  
      * 제목행 (제목, 수정일 있는 행)   
        * 고정 : 스크롤해도 위로 밀려나지 않는다.  
        * 강조 : 제목행은 바탕색을 살짝만 톤을 주어서 강조한다.  
        * 가로 구분선 제거 : 현재 폴더뷰에서 클레이 영역의 상단 가운데에 불필요한 가로구분선이 남아있으니 이를 제거.

* 왼쪽, 오른쪽 사이드바 경계선 조절 기능 추가 및 UI 통일  
  * 이유 : (1) 하위 폴더 위계가 증가, (2) 긴 폴더명 때문에 전체 폴더명이 잘려 식별이 어려움  
  * 구현 방식 : 오른쪽 드로어 창(댓글, ai agent) 크기조절 방식과 동일하게, 통일된 방식으로  
  * VCS 드로어에도 동일하게 크기 조절 기능 부여  
  * 추후 우측 또는 좌측에 새로운 기능 드로어를 만들때, 통일된 방식으로 적용  
  * ProblemView의 우측 사이드바(메뉴, 공유, 블록체인 원본인증)에도 동일한 기준(폭 너비, 크기 조절 기능)을 적용
