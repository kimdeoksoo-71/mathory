Phase 63 : FolderView 디자인 개선

\<리스트 보기 기능 개선\>

* 세로스크롤 시 리스트의 각 줄이 제목바 아래로 밀려들어갈 때, 줄의 일부만 밀려들어가는 모습이 부자연스러음. 리스트를 세로 스크롤 하면 고정된 제목행 아래로 리스트가 밀려들어가 사라질 때 줄 단위로 사라지도록 수정  
* 폴더뷰의 기본 보기는 리스트,  
  * 카드보기 상태에서 폴더를 떠났을 때 현재의 보기(리스트, 카드)를 기억,저장 하지 않는다.  
  * 같은 폴더로 다시 되돌아 왔을 때 리스트 보기로 보여준다.  
  * 카드보기는 ‘카드’ 버튼을 클릭했을 때만.  
* 리스트 제목 바의 칼럼 기능 추가  
  * 칼럼의 종류와 기본 값  
    * 기본 칼럼 : 고정  
      * 제목 : 1열에 고정  
      * 수정일 : 마지막 열에 고정  
    * 선택 칼럼 : 보이기, 가리기, 순서 변경 가능.  
      * 블록체인 원본인증  
      * 정밀 검증 결과 (문항, 해설)  
      * AI agent : 대화 개수  
      * 댓글  
    * 추후 확대될 칼럼 : 현재는 넣지 않음  
      * 해시태그  
        * 배점  
        * 대단원  
        * 등등  
  * 칼럼 폭 기본 값 및 조절  
    * 기본 값 : 전체 행에서 해당 칼럼의 폭이 가장 긴 행의 폭에 맞추어 자동 설정.  
    * 조절 가능 : 제목행에 각 칼럼들 사이에 세로 구분선이 있고, 이 선을 움직여 칼럼 폭을 조절할 수 있음  
  * 칼럼 보이기, 순서 기본 설정값  
    * 모든 폴더에 대하여 기본, 선택 칼럼 모두 ‘보이기’를 기본 설정으로  
    * 보이는 칼럼들, 칼러들의 순서, 각 칼럼들의 폭은 각각의 폴더에 대하여 항상 저장. 폴더를 드나들어도 설정된 값을 유지.  
  * 칼럼 내용을 기준으로 한 리스트 소팅 기능  
    * 소팅 결과는 저장되고, 폴더를 드나들어도 설정된 값을 유지.

\<타당성 검토 의뢰\>

* 현재 하나의 폴더 안에서 문제와 하위 폴더 보기를 구역을 나누어서 보여주고 있어.   
  * 하위폴더 : 상단 2행에 폴더 바를 두고 각 폴더명을 사각형으로 둘러 버튼화 한 뒤 가로로 배열, 스크롤 가능  
  * 문제 : 리스트보기, 카드 보기로 구별하여 아래에 배열  
* 문제점 : 카드보기에서는 현행의 폴더/문제 구별이 자연스러우나, 리스트 보기에는 불편하고 부자연스러움  
* 타당성 검토 의뢰내용   
  * 리스트 보기에서 폴더, 문항을 모두 리스에 넣고 보기로 전환할 수 있나?  
    * 상단 2행( 폴더 행)이 사라진다.  
    * 한 폴더가 한 개 행을 차지하는 폴더 목록이 리스트 상단에 나타나고, 폴더 목록 아래에 문제 목록이 나타난다.   
    * 폴더 리스트는 폴더 제목 앞에 폴더 아이콘이 들어간다.  
    * 각각의 폴더 행은  리스트와 같은 긴 가로막대의  테두리는 없다. 가운데 FolderView 의 기본 바탕에 폴더 아이콘과 수정일 날짜만 표시된다.   
    * 폴더 뷰 안에서(좌측 사이드바가 아닌) 폴더 펼치기 기능(Mac OS 파인더 앱에서와 같은)은 없다.   
    * 정렬(sorting) 기능은 폴더끼리, 문제끼리만 작동한다. 폴더와 문제가 뒤섞여 정렬되지 않는다.  
  * 리스트 보기에서 문항 드래그 앤 드롭 기능  
    * 기존 카드보기에서 가능하던 DnD기능 (상단 폴더행의 폴더에 대하여 문항을 드래그하여 드롭하는 기능)을 리스트 보기에서 구현 가능한가?  
    * 가능하다면 리스트 보기에서 여러개의 문항을 동시에 선택하여 한꺼번에 폴더에 넣기를 구현하는 것이 가능한가?
