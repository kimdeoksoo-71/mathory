블록 편집 기능 개선 : 전체 접기 기능

1. EditorView의 툴바의 블록 관련 메뉴 4개 (블록 추가, 블록 분할, 수식행 분할, AI 완성)를 다음과 같이 이동   
   1. AI 완성 : 맞춤법 검사 우측으로 이동   
   2. 블록 추가, 블록 분할, 수식행 분할 : 신설하는 블록 하단에 툴바로 이동  
2. 블록 하단 툴바  
   1. 활성화된 블록에서만 나타나고, 비활성화된 블록에서는 사라짐 (상단 바와 마찬가지)  
   2. 상단 바와 같은 모양(세로폭, 색, 구분선)  
   3. 버튼 아이콘은 기존 아이콘에서 사각 귀퉁이 브라켓을 제외한 것을 사용 ( \+, \<-\>, …)  
3. 전체 블록 접기 기능 신설  
   1. 개요 : 블록 순서 재조정시 세로 이동폭을 줄이기 위하여 블록 상단바만 남기고 내용이 숨겨지는 기능  
   2. 트리거 버튼 : 툴바의 현재 블록 영역에 있는 4개의 버튼이 사라지고 난 빈 자리에 넣는다. 트리거 버튼은 토글방식. 접힘 상태에서 한번 더 트리거 버튼을 클릭하면 전체 블록이 모두 펼쳐진다  
   3. 작동 방식 :   
      1. 접힌 상태의 블럭도 상단바의 앞쪽의 드래그 존을 클릭하여 위아래로 이동하여 원하는 위치로 가져다 놓는 기존 블록 이동 기능이 그대로 동작한다.    
      2. ctrl \+ 클릭 하면 연속된 2개 이상의 블럭을 동시에 선택할 수 있고 선택된 블럭들을 동시에 특정 위치로 이동시킬 수 있다. 선택된 2개 이상의 연속된 블럭은 이동할 때 순서가 원래 순서를 유지한다.    
      3. 접힘 상태에서 특정 블록의 바를 더블클릭하면 해당 블록만 펼쳐진다. 펼쳐진 블록의 상단바를 더블클릭하면 다시 접힌다.   
      4. 제목 블록의 경우 접힘 상태에서 상단바의 좌측 경계선이 다른 블록보다 약간 좌측으로 튀어나오게 하고 튀어나온 부분에 섹션마크(§)를 넣는다. 상단바의 내용물 (아이콘, 텍스트 등)의 위치가 접힘, 펼침에 따라 좌우로 움직이지 않도록 섹션마크의 위치를 적절히 설정한다.
