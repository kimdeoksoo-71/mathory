블록편집 기능 개선

1. 버그 개선 (1)  
   1. 버그 내용 : 편집창에서 블록 지우기를 실행완료하면 블록이 삭제된 후 자동으로 세로 스크롤이 되어 현재탭의 첫번째 블록으로 이동. 따라서 여러개의 블록을 지울때 다시 되돌아가야 하므로 번거로움  
   2. 수정 요청 : 블록 지우기를 실행해도 세로 스크롤이 자동으로 진행되는 오동작을 없애기.  
2. 블록 접기 상태에서 기능개선  
   1. 현행 : 블록 접기 아이콘을 클릭하여 모든 블록이 접혀진 상태에서는 블록 1개만 선택, 이동 가능  
   2. 개선 요청  
      1. 접혀진 상태에서 각 블록에 ‘요약 보기’ 버튼, 삭제 버튼 보여주기. 작동가능하도록 하기.  
      2. 접혀진 상태에서 연속된 2개 이상의 블록을 동시에 선택해서 이동 가능하도록 하기.  
      3. 접혀진 상태에서 선택된 블록을 표시할때 현행은 그림자 넣기인데, 펼쳐진 상태에서 선택된 블록과 그렇지 않은 블록을 구분할때와 동일한 통일된 ‘바탕색+그림자’ 구별을 적용하자.
