ProblemView 디자인 개선

* 정방향 스크롤때 문제카드, 제목행 축소 방식  
  * 현재 제목행 \+ 빈 문제카드는 공간 낭비  
  * 개선 방향  
    * 1단계 : 문제제목행 1행이 사라지고 그 자리까지 문제 카드가 위로 밀려올라간다.  
    * 2단계 : 문제 카드가 가늘게 접히고 색이 짙어지며 그 안에 제목을 비롯한 본래 1행의 내용 (제목 \+ 댓글 등 기타 정보)이 들어간다.   
    * 문제 카드가 축소 되었을때 글자 크기는 리스트 보기와 같게 한다.  
    * 축소된 카드를 클릭하여 펼처진 문제 카드 안에는 다음 내용이 보인다..  
      * 첫줄 : 제목과 기타정보  
      * 첫줄 아래 : 가는 구분선  
      * 문제 본문

* 풀이카드   
  * 스크롤을 하지 않았을 때, 즉 최조 상태에서는 상단 가로선이 보이지 않고, 따라서 가로선 아래 페이드 아웃도 보이지 않는다. 풀이 카드의 상단은 둥근 모서리와 상단 경계선이 정상적으로 보인다.  
  * 스크롤을 시작하면  
    * 상단 경계선이 등장한다.  
    * 상당 경계선 아래 페이드 아웃효과도 나타난다.  
    * 페이드아웃 색이 현재 흰색인데, 클레이 색으로 페이드 아웃된다. (카드 보기에서 문제의 하단부분이 경계선 위에서 페이드 아웃될때와 마찬가지로

* 좌측 라벨과 중앙 컨텐츠 사이의 간격 : 현재 간격의 절반으로 줄여 가로 공간의 낭비를 줄이자.

* 요약보기에서 펼침, 접힘   
  * 현재의 노브는 없앤다. 간결함을 저해하는 요소로 작용되고 배경톤 진해짐 효과와 기능 중복  
  * 접힘 상태에서 hover시 제목행의 배경 톤 진해짐 효과 개선  
    * 접힘 상태에서 hover 하면 카드의 기본 클레이 색보다 톤이 두 단계 더 진해진다.  
    * 펼침 상태에서는 펼쳐진 내용영역 전체가 카드의 기본 클레이 색보다 톤이 한 단계 더 진해진다.   
    * 배경톤 진해짐 효과의 영역 확대 :   
      * 가로 : 카드의 왼쪽 경계선부터 오른쪽 경계선까지   
      * 세로 : 평침 상태에서는 평쳐진 영역 전체

* 경우 블록의 rail 위치 이동  
  * 현재 : 카드의 왼쪽 경계와 지나치게 붙어있어 답답한 느낌  
  * 접힘, 펼침 노브를 없애면 우측에 여유공간이 생기므로 현재보다 우측으로 이동할 여지가 생김.  
  * 카드의 왼쪽 경계선과 본문 내용의 왼쪽 끝 사이 적절한 중간위치로 이동. 현재보다 오른쪽으로.
