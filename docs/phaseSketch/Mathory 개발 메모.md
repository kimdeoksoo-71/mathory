이모지 시스템 교체

* 현재의 이모지 시스템을 phosphor로 교체  
  * 취지 : 현재 이모지 시스템은 모양이 복잡하고 컬러가 다양해 앱 전체의 디자인 컨셉인 ‘보수적인 차분함. 신뢰성 높게 착오없이 작동하는 안정감. 차분함’과 맞지 않아 단색조의 차분한 phosphor로 교체한다.  
  * phosphor의 모든 이모지를 빠짐없이 설치한다.   
  * regular, bold 모두 사용 하도록 하되, bold는 강조 상황에서만 시스템이 사용하고, 사용자가 선택하는 것은 regular 범위로 제한한다.   
  * 저작권법을 준수하기 위한 알림 준칙을 준수하기 위한 방안을 마련한다.   
* 아이콘 교체 : 아래의 아이콘을  phosphor의 아이콘으로 교체한다.  
  * 좌측사이드바, FolderView의 폴더 아이콘 교체  
    * 최상위 폴더는 : folder  
    * 그 이하 단계 폴더는 : folder-simple  
    * 사이드바에서 폴더가 펼쳐지면 : folder-open  
  * 아카이브 아이콘 교체 : archieve  
  * Agent 아이콘 교체 : lego-smily
