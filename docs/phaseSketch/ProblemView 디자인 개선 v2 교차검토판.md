## 1. ⚠ v1 정정 (W1~W4)

| # | 내용 | 귀결 |
|---|---|---|
| **W1** | **페이드는 "풀이 카드 안쪽 상단"이 아니라 "카드 안의 sticky 요소"여야 한다.** v1 Q3는 위치만 말하고 거동을 말하지 않았다. 카드 top에 고정하면 카드가 스크롤로 잘릴 때 페이드도 함께 올라가 **선에서 떨어진다**. `position:sticky; top:<커튼 높이>`로 두면 카드가 잘려도 페이드가 선 아래에 머물고, **컨테이닝 블록이 카드라 항상 클레이 위**에 있다(실측: top 400에서 페이드 0–14, 카드 −233–843) | Q3′ |
| **W2** | ❌ **선과 페이드가 둘 다 `top:0`이면 겹친다.** 실측에서 커튼 0–8, 페이드 0–14 → 페이드 상단 8px이 커튼(zIndex 상위)에 가려 **실효 6px**이 된다. 페이드의 `top`은 **커튼 높이와 같아야** 한다 → 두 값을 한 상수(`CURTAIN_H`)가 공급할 것 | Q3′ |
| **W3** | 카드 숨김 상태에서 선이 **20px 내려와 있다**(래퍼 `paddingTop 12` + 커튼 `marginTop 8`). 메모의 "가로선은 제목행 아래"에 맞추려면 **숨김일 때 래퍼 상단 여백을 0으로** | P3′ |
| **W4** | v1 P4의 "최초 진입엔 버튼 없음"은 상태 이름을 안 정했다. `!questionShown`으로 판정하면 **'문제 보기'로 되살린 뒤 버튼이 사라져** 다시 감출 수 없다. 조건은 **`hasHidden`(한 번이라도 숨긴 적 있음)** 이다 | P4′ |

## 2. v1 결정 개정

| # | 개정 |
|---|---|
| **P3′** | 숨김 = `position:absolute; visibility:hidden; pointerEvents:none`(v1 유지) **+ 숨김일 때 래퍼 `paddingTop: 0`**(W3) |
| **P4′** | 알약 버튼 렌더 조건 = **`hasHidden`**. 한 번 숨긴 뒤로는 상태와 무관하게 계속 보인다(라벨만 '문제 보기' ↔ '문제 감추기'). E-P3(자동 복원 없음)과 짝을 이룬다 |
| **Q3′** | 페이드 = **풀이 카드 안의 sticky 요소**: `position:sticky; top: CURTAIN_H; height: 14; margin-bottom: -14; margin-left: -CARD_PAD_L; margin-right: -CARD_PAD_R;` 배경 `linear-gradient(to bottom, var(--bg-content), transparent)`.<br>⚠ 좌우 음수 마진은 **패딩 상수와 같은 값을 참조**할 것(R3′로 좌측이 em이 되므로 숫자를 굳히면 갈린다) |
| **Q5′** | 선(커튼)은 sticky 블록으로 두고 **그 안에 선을 그린다**(높이 `CURTAIN_H`, 배경 `--bg-functional`). 배경이 불투명해야 선 위로 올라온 내용이 비치지 않는다 — M2에서 sticky 래퍼가 아이보리를 칠하던 이유와 같다 |
| **R3′** | `CARD_PAD_L` **px → em**(2.8em), `CARD_PAD_R`는 **px 유지**(36).<br>⚠ 좌측만 em인 이유: 좌측 패딩은 **거터(rail·dot)를 담는 그릇**이라 글꼴에 비례해야 하고, 우측은 그냥 여백이다. 둘 다 em으로 하면 fs24에서 카드가 49px 더 넓어진다 |
| **S5**(신설) | v1 V4("톤 배경이 rail을 덮는가")는 **덮지 않는다** — 톤 배경은 조상(구역 래퍼)에 있고 rail은 `.case-block::before`(자손)라 **자손이 위에 그려진다**. 별도 처방 불필요. 단 톤을 **형제 오버레이**로 만들면 그때는 덮이므로, 반드시 조상 배경으로 구현할 것 |
