## 6. 하지 말 것 / 주의

- `EditorPreview`·`lib/locale.ts` 전처리 **두 사본을 같이 고칠 것**(CLAUDE.md). 새 정규식 상수는 `lib/caseBlock.ts`/`lib/locale.ts`에만 두고 사본 금지.
- `$$` 앞뒤 빈 줄 정규화는 `toPersistedBlock`(`normalizeDisplayMathSpacing`) 소유 — 분할 결과에 중복 구현 금지.
- 700 웨이트 금지(globals.css:119-123). `case-ref`·원문자 모두 토큰 범위 안.
- 다크 토큰 없음. `scrollIntoView` 금지. 마커 리터럴을 "친절히" 다른 표기로 바꾸지 말 것(61a §7) — `(ㄱ)`→`(1)`은 덕수가 명시한 표준 변환이므로 예외.
- `tabular` 변환은 확신 없는 형태(`\multicolumn` 등)를 **그대로 둔다**. 절반만 변환된 표를 내보내지 말 것.
- 표 블록에 메타(열폭 등)를 붙이지 말 것 — 붙이는 순간 `normalize.ts`·버전 canonicalize가 따라온다.
